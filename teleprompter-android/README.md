# Телесуфлер PRO для Android (Нативное приложение)

Нативное приложение-телесуфлер на **Kotlin** с использованием **Android Jetpack CameraX**, поддержкой импорта файлов **Microsoft Word (.docx)** и записью видео с фронтальной камеры.

---

## Ключевые особенности

1. **Расположение под фронтальной камерой**:
   - Окно телесуфлера зафиксировано в самом верху экрана (`WindowInsetsCompat` / `DisplayCutoutCompat`).
   - Спикер читает бегущую строку и смотрит точно в глазок фронтальной камеры, сохраняя естественный контакт со зрителем.
2. **Сверхплавная бегущая строка**:
   - Анимация на базе `Choreographer` (синхронизация с 60Hz / 120Hz экранами смартфонов).
   - Точная регулировка темпа чтения (от 1.0x до 10.0x) кнопками `+` и `-` или ползунком.
   - Пауза и старт в одно касание по тексту или кнопке.
   - Перемотка в начало текста.
   - Режим горизонтального отражения (Mirror Mode) для профессиональных стекол-суфлеров.
3. **Прямое чтение файлов DOCX**:
   - Встроенный потоковый парсер `DocxReader` на базе `ZipInputStream` и `XmlPullParser`.
   - Не требует тяжелых сторонних библиотек (Apache POI).
   - Корректно извлекает параграфы и сохраняет структуру сценария.
4. **Встроенная видеозапись со звуком**:
   - Высокое качество HD/FHD через Jetpack CameraX `VideoCapture`.
   - Включение микрофона (`withAudioEnabled()`).
   - Автоматический старт суфлера при начале записи и пауза при остановке.
   - Сохранение напрямую в галерею смартфона (`Movies/Teleprompter`) через Android `MediaStore API`.
   - Таймер записи и индикатор REC.
   - Кнопка быстрого переключения между фронтальной и основной камерой.

## Структура проекта

```
teleprompter-android/
├── app/
│   ├── build.gradle.kts           # Зависимости CameraX, Lifecycle, Coroutines
│   └── src/
│       └── main/
│           ├── AndroidManifest.xml # Разрешения Камеры, Аудио и Хранилища
│           ├── java/com/teleprompter/app/
│           │   ├── MainActivity.kt           # Главный экран: CameraX, MediaStore, UI
│           │   ├── DocxReader.kt             # Потоковый парсер DOCX без сторонних JAR
│           │   └── TeleprompterController.kt # Движок плавной прокрутки (Choreographer)
│           └── res/
│               ├── layout/
│               │   ├── activity_main.xml     # Главная разметка с оверлеем и HUD
│               │   └── dialog_settings.xml   # Шторка настроек скорости и шрифта
│               ├── drawable/                 # Glassmorphism фоны и векторные иконки
│               └── values/                   # Цвета, строки, темы
├── build.gradle.kts
├── settings.gradle.kts
└── gradlew.bat
```

## Инструкция по сборке и запуску в Android Studio

1. Откройте **Android Studio**.
2. Выберите **File -> Open...** и укажите папку `c:\Projects\teleprompter-android`.
3. Дождитесь автоматической синхронизации Gradle (Gradle Sync).
4. Подключите Android-смартфон по USB (с включенной «Отладкой по USB») или запустите эмулятор с поддержкой камеры.
5. Нажмите кнопку **Run** (зеленый треугольник `Shift + F10`) для установки и запуска приложения.

### Сборка APK из командной строки:
```bash
cd teleprompter-android
./gradlew assembleDebug
```
Готовый установочный файл APK будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`
